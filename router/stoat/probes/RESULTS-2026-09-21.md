## Findings

1. **A lane demonstrably sustains 1M context with accurate retrieval: the
   KEYED nvidia lane, `nvidia/nemotron-3-super-120b-a12b`** — 100k (9.2s),
   500k (18.2s), 1M (41.4s), exact passphrase every time. This is the first
   verified 1M-context evidence anywhere in the estate.
2. **The `:free` nemotron ID caps at 262,144 tokens** (stated by the endpoint
   itself) — 500k/1M impossible there. Its verified ceiling is 256k-class with
   accurate 100k retrieval in ~1.1s. A "free pool 1M default" cannot name the
   `:free` ID — any 1M promotion must name the KEYED lane explicitly.
3. **The nvidia lane flaps hard**: 503-down for ~40 min mid-probe (both IDs,
   ~200 ms fast-reject, "Service temporarily overloaded" / worker
   ResourceExhausted), then clean 200s. The router's elo already demotes it
   while flapping (904, half-open) — working as designed. Any promotion must
   not fight the circuit breaker.
4. **The 200-empty pattern is real but prompt-dependent**: a bare "reply PONG"
   instruction returned HTTP 200 with empty content; a normal question on the
   same lane/model returned a real answer minutes later. Do not score 200-empty
   as "lane alive".
5. **Cost caveat (the Architect's call)**: 1M-token prompts on the keyed lane consume
   the NVIDIA build-key credits. Promotion routes real traffic at real cost —
   surface plainly, never route around.
